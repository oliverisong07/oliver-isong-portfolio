# Oliver Isong — Portfolio

A responsive personal portfolio for Oliver Clement Isong, a Software Engineering student at Babcock University.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Customize

Update social links and contact details, skills, and project information in `src/data.js`. Replace the education placeholders and add project repository and demo URLs when available.

The CV buttons open the browser print dialog. Choose **Save as PDF** to download a copy.
